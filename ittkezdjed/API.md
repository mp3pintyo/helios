## Page API

### `heliosBusy() → string`

What the engine is waiting for, e.g. "Compiling GPU shaders… 4 s (31 / 52)" while the browser compiles the pipelines of the first image (or "Compiling GPU shaders… 2 s" for a new scene's or a feature's that a frame needs at once; the canvas keeps its last frame meanwhile); empty while it renders. A page can show it over the canvas until `heliosFrames` counts a frame.

### `heliosError() → string`

Why the engine stopped, or empty while it starts or runs: the start-up error (no WebGPU, a scene file or model that failed to load, …) or the lost GPU device. The status element shows the same text, but also progress; a page polling for readiness checks this to stop waiting.

### `heliosFrames() → number`

Frames presented so far (0 until the first image is on the canvas).

### `heliosGpuMemory(table: boolean) → string`

The GPU memory the page holds, by subsystem, as JSON: `{"total": bytes, "peak": bytes, "failures": 0, "categories": {"shadows: virtual shadow maps": bytes, …}, "labels": [[label, category, bytes, count], …]}` — every live `GPUBuffer` / `GPUTexture` (destroyed or collected ones leave the ledger). `table`: the same as the text table the native `--gpu-memory` logs.

### `heliosGpuPasses(reset: boolean) → string`

Per-pass GPU times (timestamp queries) as JSON, `{"frames": 120, "frame": 8.1, "passes": {"tsr": 0.11, …}}`: each pass's minimum since the last reset (`reset`: start a new window). Empty without timestamp queries or before the engine runs.

### `heliosHud() → string`

The HUD text (timings, statistics, feature states); empty until the engine runs.

### `heliosKey(code: string) → void`

Presses a hotkey once, by its `KeyboardEvent.code` (e.g. `KeyG` toggles GI), as if typed.

### `heliosLoadModel(url: string) → Promise<boolean> (rejects on error)`

Fetches a glTF model (`.glb`, or `.gltf` with its files; relative to the page, as `?gltf=`) and rebuilds the engine with it as the scene; skinned models play their first clip. Resolves to whether the engine was running; rejects with the import error.

### `heliosLoadScene(name: string) → Promise<boolean>`

Rebuilds the engine with another scene (`valley`, `cathedral`, `forest` or `gallery`). The meshes bake in the bake workers while the current scene keeps running (without workers the bake blocks the page for a few seconds, so show a notice and yield a frame before calling). Resolves once the new scene is in, to whether the scene name was known and the engine running.

### `heliosLookAt(eyeX: number, eyeH: number, eyeZ: number, atX: number, atH: number, atZ: number) → void`

Places the camera at `eye` looking at `at`; heights are relative to the ground below each point (as the native `--eye` / `--at` flags).

### `heliosPhoto(samples: number) → void`

Takes a photo: `samples` frames accumulated into one still from the current camera, each with a new sub-pixel jitter and, with depth of field on (`KeyB`), a lens sample focused like the real-time depth of field (film-quality bokeh instead of the post-process blur). The scene's clock stands still meanwhile; the finished still stays on the canvas until the camera moves or `heliosPhoto(0)` returns to the real-time image. Poll `heliosPhotoProgress`.

### `heliosPhotoProgress() → string`

The photo's progress as JSON, `{"accumulated": 37, "samples": 128, "focusing": false, "done": false}`, or an empty string without a photo.

### `heliosReady() → boolean`

Whether the start-up finished: the scene is built and a `sceneFile`'s edits are applied, so the camera, editor and scene calls act on the final scene (the first image may still be compiling: see `heliosFrames`).

### `heliosScene() → string`

The current scene's name; empty until the engine runs.

### `heliosSetCampfireSmoke(scale: number) → void`

Scales the forest campfire's soot from its next build (`heliosLoadScene`; 1 by default, as the native `--campfire-smoke`): a smokier fire whose volume shadow shows plainly.

### `heliosSetCandleLights(count: number) → void`

Sets how many candle flames light the cathedral from its next build (`heliosLoadScene`): every flame a shadow-casting light, up to 1008 (`heliosConfig.lights` at start); 0 restores the 33 fixture lights.

### `heliosSetLantern(on: boolean) → void`

Sets whether a lantern is carried down the cathedral's nave from its next build (`heliosLoadScene`; `?lantern=1` at start): a fast, sharp moving light.

### `heliosSetPaused(paused: boolean) → void`

Stops or resumes rendering (for a canvas that is hidden or scrolled out of view).

### `heliosSetSun(azimuthDeg: number, elevationDeg: number) → void`

Places the sun (degrees; negative elevations give twilight and night).

### `heliosSetView(index: number) → void`

Selects a debug view by its index (0 = lit; see the native `--view` list).

### `heliosShaders() → string`

The background shader compile as JSON: `{"compiled": 84, "total": 160, "waiting": ["shadows", …], "compiler": "Serial", "firstImageMs": …, "fullQualityMs": …}` (times from the start of the compile, 0 until reached). The features in `waiting` are off until their pipelines arrive.

## Editor API (scene editing; see Editor operations below)

### `heliosEditorActor(id: number) → string`

One actor for the Details panel and the gizmo (see `editor::describe::actor`).

### `heliosEditorApply(op: string) → string`

Applies an edit operation (JSON, see `editor::ops::EditOp`) as one undo step; an op with a `"merge"` key joins the previous step if that had the same key (sliders, light drags). Returns `{"created": {...}}` or `{"error": "..."}`.

### `heliosEditorCamera() → number[]`

Camera for the overlay: unjittered view-projection (16, column-major), eye (3), forward (3), vertical field of view (radians), canvas CSS width and height.

### `heliosEditorCompact() → number[]`

Removes the free instance and light slots of deleted things now (otherwise done once the editor has been idle for a while); returns [instances, lights] removed.

### `heliosEditorFocus(lo: number[], hi: number[]) → void`

Frames the box `lo`–`hi` (F).

### `heliosEditorGroundAt(x: number, y: number) → number[]`

Where the ray through canvas point (x, y) meets the ground (empty if it doesn't): placement for drag and drop without waiting for a pick.

### `heliosEditorImport(url: string, bytes: Uint8Array?) → Promise`

Imports a glTF model as a content item: fetched from `url`, or parsed from `bytes` (a dropped `.glb`; `url` is then its file name). Resolves with the item id.

### `heliosEditorInstance(index: number) → string`

One instance for the Details panel.

### `heliosEditorLoad(json: string) → Promise`

Loads a scene file: rebuilds its base scene if needed, imports its models, applies its edits. Resolves when done; rejects with a message.

### `heliosEditorMovableDrags(on: boolean) → void`

Measurements: `false` makes drags move instances as they are (static: the shadow pages under them re-render in full every frame), the behaviour before actors; `true` (default) makes them movable while dragged.

### `heliosEditorPick(x: number, y: number) → number`

Asks what lies under canvas point (x, y) in CSS pixels; returns the pick's id. The answer arrives a frame or two later from `heliosEditorPickResult`.

### `heliosEditorPickResult() → string`

The latest finished pick as JSON (instance, owner, world position and normal, ground hit), or an empty string.

### `heliosEditorPreview(instances: number[], values: number[]) → void`

Moves instances' components during a gizmo drag without an undo step: 10 numbers per instance (translation, rotation quaternion, scale).

### `heliosEditorPreviewActors(actors: number[], values: number[]) → void`

Moves actors (with their children and components) during a gizmo drag without an undo step: 10 numbers of world transform per actor. Their instances move as movable ones until the drag settles.

### `heliosEditorPreviewComponents(json: string) → void`

Moves components during a drag: JSON `[{actor, component, t, r, s}]` (world transforms).

### `heliosEditorRedo() → boolean`

(undocumented)

### `heliosEditorRevertPreview(instances: number[]) → void`

Puts previewed actors and components back where the document has them (a cancelled drag).

### `heliosEditorRevision() → number`

Increments whenever an edit changed the scene (cheap: poll it to refresh panels).

### `heliosEditorSave() → string`

The scene file (`.helios.json`) of the current edits.

### `heliosEditorSelect(json: string) → void`

The selection: JSON `{actors: [id…], components: [[actor, name]…]}`; the viewport outlines their instances (an actor's children too).

### `heliosEditorSetSelection(instances: number[]) → void`

Instances outlined in the viewport (their components; see `heliosEditorSelect`).

### `heliosEditorState() → string`

The whole editable scene (see `editor::describe::state`).

### `heliosEditorUndo() → boolean`

(undocumented)

### `heliosMaterialNodes() → string`

The material graph editor's palette: every node type (pins, defaults, properties) and the preset graphs (id, label, graph).

### `heliosSetEditorMode(on: boolean) → void`

Switches the editor tools on (selection outline, picking; the editor UI owns the keyboard and the left mouse button, the camera flies while the right button is held) or off.

## Editor operations

`heliosEditorApply(JSON.stringify({ op: "<name>", …fields }))` applies one as an undo step and returns
`{"created": {actors, instances, lights, pcg}}` or `{"error": "…"}` (helios-boot.js `apply()` throws
instead). Actors are addressed by live id (from `heliosEditorState().actors`), components by
`{actor, component}`, instances and lights by scene index. An op may carry `merge: "key"` to join the
previous step with the same key (slider drags).

* **`actor_transform`**: World transforms of actors (one per actor); an actor whose ancestor is listed too moves with it.
  * `actors`: number[]
  * `transforms`: Trs[]
* **`actor_local`**: Transforms of actors relative to their parents (the Details panel).
  * `actors`: number[]
  * `transforms`: Trs[]
* **`actor_visibility`**
  * `actors`: number[]
  * `visible`: boolean
* **`rename`**
  * `actor`: number
  * `name`: string
* **`reparent`**: Attaches actors to `parent` (none: the world root), keeping where they are.
  * `actors`: number[]
  * `parent?`: number
* **`group`**: A new actor at the actors' centre with them as its children.
  * `actors`: number[]
  * `name?`: string
* **`ungroup`**: Moves the children of each actor up to its parent and deletes it if it has no components.
  * `actors`: number[]
* **`component_transform`**: World transforms of components.
  * `components`: ComponentRef[]
  * `transforms`: Trs[]
* **`component_local`**: Transforms of components relative to their actors.
  * `components`: ComponentRef[]
  * `transforms`: Trs[]
* **`component_visibility`**
  * `components`: ComponentRef[]
  * `visible`: boolean
* **`component_light`**: A light component's light (world space).
  * `component`: ComponentRef
  * `def`: LightDef
* **`transform`**: Sets instance transforms (scene indices, one per instance).
  * `instances`: number[]
  * `transforms`: Trs[]
* **`visibility`**
  * `instances`: number[]
  * `visible`: boolean
* **`assign_material`**
  * `instances?`: number[]
  * `components?`: ComponentRef[]
  * `actors?`: number[]: Every mesh component of these actors.
  * `material`: string
* **`cast_shadow`**
  * `instances?`: number[]
  * `components?`: ComponentRef[]
  * `cast_shadow`: boolean
* **`delete`**: Deletes actors with everything below them, components, instances, lights (scene indices) and PCG volumes.
  * `actors?`: number[]
  * `components?`: ComponentRef[]
  * `instances?`: number[]
  * `lights?`: number[]
  * `pcg?`: number[]
* **`duplicate`**: Copies actors with everything below them (instances and lights: their actors) and PCG volumes, moved by `offset`.
  * `actors?`: number[]
  * `instances?`: number[]
  * `lights?`: number[]
  * `pcg?`: number[]
  * `offset`: [number × 3]
* **`place`**: Places a content item (engine prefab, imported model, `mesh:NAME`) as a new actor.
  * `item`: string
  * `transform`: Trs
  * `parent?`: number
* **`material`**
  * `name`: string
  * `params`: MaterialParams
* **`graph`**: Creates or replaces a material graph (by name).
  * `name`: string
  * `graph`: MaterialGraph (copy one from heliosEditorState().graphs or heliosMaterialNodes().presets)
* **`light`**: A light by scene index (world space).
  * `light`: number
  * `def`: LightDef
* **`add_light`**: A new light actor (world space).
  * `def`: LightDef
* **`environment`**
  * `env`: Environment
* **`render`**
  * `key`: string
  * `value`: any JSON value
* **`add_pcg`**
  * `preset`: string
  * `center`: [number × 3]
* **`pcg`**
  * `def`: PcgVolumeDef

## Data types (scene files and editor operations)

Scene files (`.helios.json`, `heliosConfig.sceneFile`) are a `SceneDoc` with `"format": "helios-scene"` and
`"version": 2`. Optional fields (`?`) may be left out. The editor's Save (Ctrl+S in `editor.html`)
writes one, the easiest way to get a valid file to start from.

### `Trs`

Translation, rotation (quaternion x, y, z, w) and scale.

  * `t`: [number × 3]
  * `r`: [number × 4]
  * `s`: [number × 3]

### `ComponentRef`

A component: its actor's live id and its name.

  * `actor`: number
  * `component`: string

### `LightDef`

A local light, complete (lights are small, so edits store all of it).

  * `shape`: LightShape
  * `position`: [number × 3]
  * `direction?`: [number × 3]: Spot direction.
  * `color`: [number × 3]
  * `intensity`: number
  * `range`: number
  * `source_radius`: number
  * `cast_shadows`: boolean
  * `inner_deg?`: number: Spot cone half-angles in degrees.
  * `outer_deg?`: number
  * `enabled?`: boolean: Deleted lights stay in the list (handles don't shift) but are switched off.

### `LightShape`

One of:
* `"point"`
* `"spot"`

### `MaterialParams`

Material parameter overrides (absent fields keep the base value).

  * `base_color?`: [number × 3]
  * `roughness?`: number
  * `metallic?`: number
  * `opacity?`: number
  * `emissive?`: number: Emission as a multiple of the base colour.
  * `emissive_color?`: [number × 3]
  * `normal_strength?`: number
  * `uv_scale?`: number
  * `graph?`: string: The material graph by name (`""`: none).
  * `parameters?`: { [name]: ParameterDef }: Graph parameter values of this material (a material instance), by parameter name.
  * `slab?`: SlabDef: Substrate slab overrides.
  * `displacement?`: DisplacementDef: Displacement (Nanite tessellation) overrides.

### `SlabDef`

Substrate slab overrides (absent fields keep the base value; see `helios_render::Slab`).

  * `ior?`: number
  * `specular?`: number
  * `clearcoat?`: number
  * `clearcoat_roughness?`: number
  * `sheen_color?`: [number × 3]
  * `sheen_roughness?`: number
  * `subsurface?`: number
  * `subsurface_color?`: [number × 3]
  * `subsurface_radius?`: number
  * `transmission?`: number
  * `anisotropy?`: number
  * `unlit?`: boolean

### `DisplacementDef`

Displacement overrides (see `helios_render::Displacement`): a material without one gets one by its own texture's height; a magnitude of 0 removes it.

  * `magnitude?`: number: Object-space distance between heights 0 and 1.
  * `center?`: number: Height that stays in place.
  * `channel?`: number: Channel of the height layer's data texel (3: a procedural texture's height).

### `ParameterDef`

A graph parameter's value (texture parameters are not stored: textures have no names).

Untagged: one of:
* `Scalar`
  * `value`: number
* `Vector`
  * `value`: [number × 4]

### `Environment`

Sun, sky and air (UE's directional light, sky atmosphere, height fog, clouds and wind).

  * `sun_azimuth_deg`: number
  * `sun_elevation_deg`: number
  * `sun_intensity`: number
  * `fog`: FogDef
  * `clouds`: CloudsDef
  * `wind`: WindDef

### `FogDef`

  * `density`: number
  * `height_falloff`: number
  * `base_height`: number
  * `albedo`: [number × 3]
  * `anisotropy`: number
  * `ambient`: number
  * `noise`: number
  * `distance`: number

### `CloudsDef`

  * `coverage`: number
  * `density`: number
  * `base_altitude`: number
  * `thickness`: number
  * `wind`: [number × 2]
  * `shadow_strength`: number

### `WindDef`

  * `direction`: [number × 2]
  * `strength`: number
  * `gust_frequency`: number
  * `gust_wavelength`: number
  * `turbulence`: number

### `SceneDoc`

  * `format`: string
  * `version`: number
  * `base`: BaseScene
  * `camera?`: CameraDef
  * `imports?`: ImportDef[]
  * `actors?`: { [name]: ActorEdit }: Overrides of the base scene's actors by key.
  * `added_actors?`: AddedActor[]
  * `materials?`: { [name]: MaterialParams }
  * `graphs?`: { [name]: MaterialGraph (copy one from heliosEditorState().graphs or heliosMaterialNodes().presets) }: Material graphs created or edited in the editor, by name (they replace a base scene's graph of the same name).
  * `environment?`: Environment
  * `render?`: { [name]: any JSON value }: Render setting overrides by key (see `settings.rs`).
  * `pcg?`: PcgVolumeDef[]
  * `pcg_output?`: PcgOutputDef[]: Generated PCG instances; only in saved files (the live document keeps them in a cache, so undo snapshots stay small).
  * `next_id?`: number: Next id for added instances, lights and volumes.

### `BaseScene`

What the edits apply to.

Tagged by `"kind"`: one of:
* `"procedural"`: A procedural demo scene (`valley`, `cathedral`, `forest`) at a detail (`medium`, `high`): both change the instance list, so both are part of the identity.
  * `scene`: string
  * `detail`: string
* `"gltf"`: A glTF model (URL relative to the page, or a file path relative to the scene file).
  * `url`: string
  * `ground?`: boolean

### `CameraDef`

  * `position`: [number × 3]
  * `yaw_deg`: number
  * `pitch_deg`: number
  * `fov_deg`: number

### `ImportDef`

A glTF model imported into the scene; its meshes and materials are named `name/…`.

  * `name`: string
  * `url`: string

### `ActorEdit`

Overrides of an actor of the base scene, by its key (absent fields keep the base value).

  * `name?`: string
  * `parent?`: string: Another parent: an actor key (`+ID` for an added actor), or `""` for the world root.
  * `transform?`: Trs: Transform relative to the parent.
  * `visible?`: boolean
  * `deleted?`: boolean
  * `components?`: { [name]: ComponentEdit }: Component overrides by component name.

### `ComponentEdit`

Overrides of a base actor's component.

  * `transform?`: Trs: Transform relative to the actor.
  * `visible?`: boolean
  * `material?`: string
  * `cast_shadow?`: boolean
  * `light?`: LightDef: A light component's light, its position and direction relative to the actor.
  * `deleted?`: boolean

### `AddedActor`

An actor added in the editor (placed content, a light, a duplicate, a group); its key is `+ID`.

  * `id`: number
  * `name`: string
  * `parent?`: string: The parent's key (none: the world root).
  * `transform?`: Trs: Transform relative to the parent.
  * `visible?`: boolean
  * `components?`: ComponentDef[]

### `ComponentDef`

A component of an added actor.

  * `name`: string
  * `transform?`: Trs: Transform relative to the actor.
  * `visible?`: boolean
  * `kind`: ComponentKindDef: (flattened: its fields sit in this object)

### `ComponentKindDef`

Tagged by `"kind"`: one of:
* `"mesh"`
  * `mesh`: string
  * `material`: string
  * `cast_shadow?`: boolean
* `"light"`: Position and direction relative to the actor.
  * `light`: LightDef
